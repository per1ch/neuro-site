# Guide data schema (v1)

Generated by `python3 pipeline/extract.py <Neurotrauma-CS checkout> site/data`.
Everything under `site/data/` is generated: edit the extractor, not the JSON.

Ids are the mod's own identifiers. Unknown values are `null` or `[]`.
Entries with `hidden: true` are internal (overlays, triggers, sound items): don't list them.

## afflictions.json — array
| field | type | notes |
|---|---|---|
| id, name, description | string | description = in-game text with colour tags stripped (null for many: use `guide`) |
| category | string | source file: wounds, blood, bloodtypes, bones, brain, limbs, head, heart, drugs, kidneys, liver, lungs, vanilla, surgical, symptom, torso, functionality |
| kind | string | condition, symptom, vital, surgical, drug-in-blood, bloodtype, indicator, utility |
| danger | string\|null | lethal, serious, moderate, minor, beneficial, utility (from code analysis) |
| bodyParts | string[] | head, torso, leftarm, rightarm, leftleg, rightleg, or ["any"] for limb-specific |
| limbSpecific, isBuff | bool | |
| maxStrength, showInScannerThreshold | number\|null | threshold 999 = never shown on scanner |
| detectedBy | string[] | "healthscanner", "bloodanalyzer" |
| icon | {sheet,x,y,w,h,color}\|null | pixel rect into `site/data/images/<sheet>`; color is the tint |
| symptoms | id[] | symptoms this condition produces |
| symptomOf | id[] | reverse: conditions that produce this symptom (symptom checker) |
| causes | {type:"affliction"\|"item"\|"event"\|"text", id, text}[] | |
| leadsTo | id[] | afflictions this one causes |
| treatments | {item, note}[] | items that treat it |
| guide | object\|null | {howYouGetIt, whatItDoes, treatment, naturalRecovery, progression, thresholds:[{value,meaning}], source} plain-language, from code |
| code | object\|null | raw comment header from NTAfflictionsData.cs: {title,type,causedBy,effects,notes} |
| causeOfDeath | string\|null | |
| source | string | file in the mod repo |

## items.json — array
| field | type | notes |
|---|---|---|
| id, name, description | string | names of vanilla items NT overrides come from a built-in list |
| category | string | blood, bodyparts, consumable, equipment, vanilla-override, surgical, unused, internal |
| gameCategory, tags | string, string[] | from the item XML |
| icon | {sheet,x,y,w,h,color}\|null | inventory icon |
| price | number\|null | base price |
| fabricate | {fabricator,time,amount,skills:[{skill,level}],ingredients:[{item,amount}]}\|null | |
| treats, causes | id[] | affliction ids |
| treatsDetail, causesDetail | {affliction, amount, notes\|when, source}[] | |
| skill | {skill, required, notes}\|null | from code |
| skillHint | {skill, level}\|null | from XML |
| usage, onFailure, summary | string\|null | plain-language, from code analysis |
| useInHealthInterface | bool | usable from the health menu |

## surgery.json — array
`{name, goal, steps:[{item, action, requires}], notes, source}`

## systems.json — array
`{id, title, explanation, keyNumbers:[{label, value}], source}` — blood pressure, blood types, oxygen chain, CPR, damage mapping, pain and safe surgery, organs, infection, addiction, death.

## meta.json
`{modRepo, modCommit, generatedAt, counts, schemaVersion}`
